# Báo cáo rà soát API quản lý bác sĩ — Đức Cường — Tuần 03

## 1. Thông tin chung
- **Người thực hiện:** Đức Cường
- **Công cụ:** Postman
- **API rà soát:**
  1. `GET /api/admin/doctors`
  2. `POST /api/admin/doctors`
- **Mục tiêu:** Rà soát phản hồi API, tham số đầu vào, body, headers, xác thực và các trường hợp dữ liệu phù hợp.
- **Môi trường:** HMS Local
- **Thời điểm thực hiện:** Tháng 10/2026

## 3. Kết quả kiểm thử — POST /api/admin/doctors
| Test ID | Trường hợp | Status Code | Kết quả thực tế / Phản hồi |
| :--- | :--- | :--- | :--- |
| **POST-02** | Trùng tài khoản/hồ sơ đã tồn tại | 409 Conflict | Trả về thông báo: *"Tài khoản này đã có hồ sơ bác sĩ."* |
| **POST-03** | Không có token | 403 Forbidden | Chặn yêu cầu tạo dữ liệu khi thiếu thông tin xác thực. |
| **POST-04** | Thiếu trường bắt buộc trong Body | 403 / 400 | Yêu cầu không được phép hoặc thiếu dữ liệu validation. |

## 4. Vấn đề cần xác minh
- **Issue 1:** Hành vi xác thực của hệ thống trả về mã `403 Forbidden` thay vì `401 Unauthorized` khi thiếu token.
- **Issue 2:** Phản hồi `409 Conflict` khi tạo trùng hồ sơ bác sĩ hoạt động chính xác theo đúng ràng buộc nghiệp vụ.
